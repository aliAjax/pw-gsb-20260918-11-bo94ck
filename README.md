# hxyfront-62008 烟花燃放脚本编排

面向烟花燃放编排师的**发射批次**前端工具：记录节目段落、烟花型号、口径、发射角度、点火时间、持续时间、安全距离和音乐时间点，支持时间轴编排、燃放点位平面图、型号清单、冲突提示与整场节目审计。

## 发射批次规则

1. **稳定排序**：批次内每枚烟花按点火秒升序排列；点火秒相同保持原顺序（表中以 `≡` 标记）。
2. **整批校验**，存在任一冲突即整批拒绝，并在清单、时间轴、平面图中标出冲突项：
   - 同一场地分区内，按发射顺序相邻两枚的点火间隔 **不足 0.8s**；
   - 任一发射点落入另一枚烟花的**安全半径**内（两点间距小于两枚安全半径的较大值，跨分区同样校验）。
3. **提交后锁定**：校验通过后批次封版，新增 / 调整 / 移除全部禁用。
4. **撤回保留记录**：撤回只解除锁定，全部分配、调整、移除及提交/拒绝/撤回历史都保留。
5. **刷新后继续**：批次、状态（含锁定）、最近一次拒绝的冲突快照与操作记录都存于 `localStorage`。

页面包含：提交面板（规则与冲突明细）、分配表单、分区时间轴、点位平面图（安全半径圆 + 冲突连线）、按发射顺序的批次清单、型号聚合和操作审计。

## 技术栈

React 19 + Vite 7 + TypeScript（状态机见 `src/state/reducer.ts`，排序与冲突校验见 `src/utils/batch.ts`）。

